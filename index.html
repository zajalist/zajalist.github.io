Plumb

2026
Hackathon
2nd · Best Use of Vultr

Basically a 3D reasoning and constraints-validation engine exposed to an LLM over MCP. A lot of the constraint-building features didn't make it in by the end of hack time, but the app itself looks quite nice: a viewport, mask layers, inspector panels, and a node editor for constraints. Once you've built up a library of 3D models and constraints, the engine can catch and auto-repair object placements by checking them against those constraints. The idea is that in a proper production setting, these constraints grow into a "grammar of world predicates".

Shaddy

2025
Hackathon
1st · Hack the Mountain

A Scratch-style visual editor for making GPU shader art. You build shaders out of blocks, but the raw GLSL stays right there and editable, and a bidirectional compiler keeps the blocks and the code in sync using magic comments. Parameters animate on the GPU.

Hayba

WIP · 2026
Tooling

An agentic MCP toolkit that drives Unreal Engine 5, including, for the first time, the functionality of hooking into the PCGExtendedToolkit. It ships with a UE5 C++ editor plugin that draws a force-directed map of the scene and lets you search assets semantically (BM25 plus embeddings). Still a work in progress.
