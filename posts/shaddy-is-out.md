title: "Shaddy is out: learn and build GPU shaders through blocks"
date: 2026-06-20
read: ~2 min
summary: An open-source sandbox for learning and constructing shaders through a simple block abstraction, now freely available at shaddy.net.
---

A few weeks ago I could not find any up-to-date online resource for getting acquainted with GPU computing, so I presented at a hackathon Shaddy: a sandbox for learning and constructing shaders through a simple block abstraction which comes alongside the ability to modify the low-level GLSL code directly and have it compile into blocks.

I am happy to announce that the open source project is now out and freely available at [shaddy.net](https://shaddy.net)! Create an account, read through the learning and documentation sections and put your knowledge to the test using the block composer. All the while, you can take pictures and videos of your resulting art and publish it in the community section.

Shaddy's V1 supports complex animation workflows, 3d raymarchers and ease-of-use features like commenting, macros and more.

As this is an early and speedy release, if you have any feedback or discover any issue, please let me know. It is a very simple website with little to no backend, every visuals run on your device. 😁
